Second prototype de l'Archipel sur Android, à installer à la main.

**Installer** : télécharger l'APK ci-dessous sur le téléphone, l'ouvrir, puis autoriser l'installation
depuis cette source quand Android le demande. Android 8 ou plus récent, WebView (Chrome) à jour. Si une
version précédente est installée et qu'Android refuse la mise à jour, la désinstaller d'abord (la sauvegarde
est alors perdue).

**Nouveautés depuis 0.1.0**
- **Couleurs fidèles** : la coque passe en thème clair et interdit tout assombrissement automatique (mode
  sombre du téléphone, « mode sombre des applis »), fenêtre en sRGB, page en `color-scheme: only light` ;
  les couleurs sont celles du jeu sur ordinateur.
- Le château du Sommet givré, visible de tout l'archipel ; massif abaissé.
- Paysages lointains peints au-delà de l'archipel ; nuages bas retirés de l'horizon.
- Refonte visuelle (ombres, herbe, roche, ciel, arbres, buissons, personnage) et musique Illumoria incluse.

**Commandes** : toucher l'écran pour ouvrir le menu et choisir ; en jeu, toucher le sol pour y aller, glisser
pour tourner la caméra ; bouton Retour = Échap (ferme un panneau). Une manette Bluetooth devrait marcher
comme sur ordinateur.

**Limites connues** : rendu peint lourd (prévoir un téléphone récent, baisser la qualité dans Options) ; pas
de commandes tactiles pour sauter, rouler ou frapper ; APK signé en mode débogage ; pas encore essayé sur un
téléphone réel.
