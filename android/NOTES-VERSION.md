Premier prototype jouable de l'Archipel sur Android, à installer à la main.

**Installer** : télécharger l'APK ci-dessous sur le téléphone, l'ouvrir, puis autoriser l'installation
depuis cette source quand Android le demande. Android 8 ou plus récent, WebView (Chrome) à jour.

**Ce que contient le prototype**
- l'écran-titre : le héros sur le Plateau venté à l'aube, thème au piano, menu (Continuer, Nouvelle partie,
  Options) ;
- l'archipel des souvenirs, à explorer ;
- la sauvegarde, gardée sur le téléphone (une désinstallation l'efface).

**Commandes** : toucher l'écran pour ouvrir le menu et choisir ; en jeu, toucher le sol pour y aller, glisser
pour tourner la caméra ; bouton Retour = Échap (ferme un panneau). Une manette Bluetooth devrait marcher
comme sur ordinateur (pas encore essayé sur téléphone).

**Limites connues** : rendu peint lourd (prévoir un téléphone récent, baisser la qualité dans Options) ; pas
de commandes tactiles pour sauter, rouler ou frapper ; APK signé en mode débogage (une nouvelle version peut
demander de désinstaller la précédente, donc de perdre la sauvegarde) ; en jeu, la boîte à musique remplace
la musique Illumoria.
